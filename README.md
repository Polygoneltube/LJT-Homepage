# LJT-Homepage

Personal academic homepage for Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and customized with the profile information available in the connected memory store.

The site includes:

- An About page with academic background, research experience, skills, honors, contact details, and the complete publication list.
- A dedicated Publications page with individual publication entries.
- A Curriculum Vitae page.

## Local development

```bash
bundle install
bundle exec jekyll serve --baseurl "/LJT-Homepage"
```

Then open `http://localhost:4000/LJT-Homepage/`.
